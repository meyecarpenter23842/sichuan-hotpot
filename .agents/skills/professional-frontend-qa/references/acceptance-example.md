# Example frontend acceptance
1. Primary action obvious without guessing.
2. UI coheres with brand, not generic AI dashboard.
3. Loading, empty, error, success and disabled flows verified.
4. Responsive 390 / 768 / 1440 CSS px where browser available.
5. Tap/keyboard controls have proper accessible names.
6. Vietnamese labels, VND and long addresses don't overflow.
7. Document PASS/FAIL/NOT TESTED with actual evidence.
8. No unrelated infra/secrets/backend changes, unapproved merge/deploy.
