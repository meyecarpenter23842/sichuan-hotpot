# Enterprise UI: operations dashboards and orders
- Lead with operational task, not decorative hero. Admin: dense, scannable layout.
- Favor action bar, search/filter, meaningful queue/table and contextual details.
- Distinguish read-only info, actions, warnings and destructive operations.
- Numeric amounts right-aligned, units and currency visible.
- Functional pagination/filter or none; empty results differ from errors/permission denial.
- On narrow devices choose condensed lists/details, not unreadable squeezed tables.
- Report transitions honestly: requested, processing, completed, failed.
- Confirm irreversible actions; never show completed until backend confirms.
- Consistent icon set, restrained cards/shadows; charts only for decisions with real data.
